🚀 Hướng Dẫn Kết Nối GitHub & Vercel Từng Bước

Chào mừng bạn! Dưới đây là quy trình hoàn chỉnh để kết nối mã nguồn Thái Ất này với tài khoản GitHub của bạn và tự động xuất bản (deploy) lên Vercel chỉ trong vài phút.

1

Khởi tạo thư mục & Đẩy mã nguồn lên GitHub

Bạn đã tạo thành công repo HoangThaiAt trên GitHub tại địa chỉ: https://github.com/hoangreno8z/HoangThaiAt.git

Bây giờ, hãy mở Terminal hoặc Git Bash tại thư mục chứa code và chạy các dòng lệnh sau để đẩy toàn bộ code ứng dụng này lên GitHub:

git init
git add .
git commit -m "Initial commit: Thai At App"
git branch -M main
git remote add origin https://github.com/hoangreno8z/HoangThaiAt.git
git push -u origin main

Lưu ý: Thay vì chỉ git add README.md, lệnh git add . sẽ thêm toàn bộ file code (index.html, style.css, script.js) vào repo!

2

Đăng nhập vào Vercel

Truy cập vào trang chủ Vercel.com.

Chọn Log In -> Chọn Continue with GitHub để liên kết tài khoản Vercel trực tiếp với GitHub của bạn.

3

Import Project

Tại trang quản trị của Vercel (Dashboard), nhấn nút Add New... rồi chọn Project.

Vercel sẽ hiển thị danh sách các kho chứa (repositories) trên GitHub của bạn. Tìm kiếm repo có tên HoangThaiAt và nhấn nút Import bên cạnh nó.

4

Deploy (Triển khai)

Ở màn hình tiếp theo, Vercel sẽ tự động phát hiện đây là một dự án HTML/CSS/JS tĩnh (Static Project). Bạn không cần thay đổi bất cứ cài đặt nào.

Chỉ cần nhấp vào nút Deploy màu xanh đen ở phía dưới.

Chờ khoảng 10-15 giây để Vercel xây dựng. Sau khi hoàn thành, bạn sẽ thấy màn hình chúc mừng kèm theo ảnh chụp màn hình trang web của bạn cùng đường dẫn truy cập trực tuyến dạng https://hoang-thai-at.vercel.app.

💡

Cơ chế Tự Động Hóa (CI/CD) của Vercel

Sau khi kết nối thành công, mỗi khi bạn thực hiện thay đổi mã nguồn trên máy tính, bạn chỉ cần gõ:

git add .
git commit -m "Cập nhật giao diện"
git push origin main

Ngay lập tức, Vercel sẽ tự động phát hiện có commit mới trên GitHub, tự động build lại và cập nhật trang web trực tuyến của bạn trong vài giây. Bạn không cần làm gì thêm trên Vercel!
